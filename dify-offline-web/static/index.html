🛠️ Dify 插件离线重打包

上传官方（或第三方）.difypkg，工具将把全部 Python 依赖（linux cp312 双架构 wheel）打进包内，生成可在完全离线 Dify（1.16+/1.17，plugin_daemon 0.6.10）上本地安装的离线包。打包机需可访问 PyPI。

点击或拖拽 .difypkg 到此处
尚未选择文件（如 webscraper.difypkg）
目标 python 固定 3.12（与 plugin_daemon 一致）；内部先 uv 精确锁定，再按 PEP425 标签抓取 wheel 并做 sha256 校验，最后注入 wheels/ 与离线依赖配置。勾选自签需服务端配置私钥（DIFY_OFFLINE_PRIVATE_KEY），目标端配合第三方公钥验签即可保持 FORCE_VERIFYING_SIGNATURE=true。

目标端部署说明（离线 Dify）

  1. 把生成的 …-offline.difypkg 拷贝进内网。
  2. 在 Dify 部署目录的 .env 增加/调整（快速路径；安全路径见文档）：
FORCE_VERIFYING_SIGNATURE=false PLUGIN_MAX_PACKAGE_SIZE=524288000 NGINX_CLIENT_MAX_BODY_SIZE=500M
  • 前一项：放行未上架/被重打包签名的本地插件（生产建议改用“自签+第三方公钥”安全路径，本期文档详述）；
  • 后两项：离线包通常大于默认 50MB 限制（上传与解压双重限制）。
docker compose up -d plugin_daemon nginx

3. 打开 Dify → 插件 → 本地文件安装 → 上传离线包 → 安装成功后即可使用（无需外网，依赖从包内 wheels/ 安装）。
