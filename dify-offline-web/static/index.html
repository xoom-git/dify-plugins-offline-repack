目标端部署说明

把生成的离线包拷入内网 Dify，在部署目录 .env 增加： 
FORCE_VERIFYING_SIGNATURE=false   # 或用第三方公钥验签（安全路径）
PLUGIN_MAX_PACKAGE_SIZE=524288000
NGINX_CLIENT_MAX_BODY_SIZE=500M
  1. docker compose up -d plugin_daemon nginx
  2. Dify → 插件 → 本地文件安装 → 上传离线包
  3. 安装全程零外网（依赖自包内 wheels/ 安装）
安全路径（推荐）：页面勾选“组织私钥自签”，服务端配置 DIFY_OFFLINE_PRIVATE_KEY，目标端开启 THIRD_PARTY_SIGNATURE_VERIFICATION_ENABLED=true 并挂载公钥，即可保持 FORCE_VERIFYING_SIGNATURE=true。详见 docs/05。
